# Installation

Install the package and import the APIs you need.

## Install

Add the package to your project dependencies.

```bash
npm i @codemonster-ru/floater.js
```

## Import

Import the functions you need from the package entry point.

```ts
import { computePosition } from '@codemonster-ru/floater.js';
```

## CSS

Floater.js does not require CSS or runtime stylesheets.
